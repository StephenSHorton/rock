01 coding cli · 1.0

Rock, is this true?

Ask it of the repo. Rock reads the files, answers in the transcript, and says when the claim does not hold. A Charm TUI, headless print, ACP on stdio, and a loopback HTTP API share one session. Jev judges the bounded calls. With no key, those gates still run, and inspect says they are offline.

install one command

Try it in your terminal.

macOS

curl -fsSL https://stephenshorton.github.io/rock/install.sh | bash

Linux

curl -fsSL https://stephenshorton.github.io/rock/install.sh | bash

Windows

irm https://stephenshorton.github.io/rock/install.ps1 | iex

Needs Go 1.27 or newer. The command installs the current 1.0 build of rock into your Go bin.

02 the agent

Built to sit in, and to be driven.

01

Charm, on purpose

Bubble Tea, Bubbles, Lip Gloss, Glamour, Huh, Log, and Harmonica. The transcript, composer, permission modal, and context meter are the product. Huh is rock setup only.

02

Four doors, one session

JSONL under ~/.rock is the session. Resume it from the TUI, from print mode, or from a Suzuri pane with the same id.

03

Jev, in the loop

Model, skill, stuck, destructive risk, subagent kind, retrieval, compaction, plan readiness. Yolo skips the ask. It does not skip the destructive block.

04

A guest in the pane

rock fork emits OSC 7880. Suzuri splits the pane and launches an allowlisted rock with ROCK_SESSION_TITLE. The host keeps the window.
